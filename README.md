# MK Draw

A notebook app for Android phones, tablets and foldables: realistic pens, handwriting to text, shapes, a ruler and backups, with no account.

**Download:** [MK-Draw.apk](https://github.com/Mkuz1/MK-Draw-releases/releases/latest/download/MK-Draw.apk) (works on every Android device)

Smaller builds for a specific processor are attached to each [release](https://github.com/Mkuz1/MK-Draw-releases/releases). Installed copies check this repository for updates.

Website: https://mkdraw.pages.dev
